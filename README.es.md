# Restricción por Tesapé para Moodle (Oksigenia Tesapé)

Una condición de disponibilidad de Moodle que abre una actividad o una sección con el progreso de
[Oksigenia Tesapé](https://github.com/OksigeniaSL/moodle-local_oksigeniatesape), el juego de rol para el aula:

- **La clase enciende la linterna de un lugar** de la misión del curso (o lo deja atrás).
- **El héroe del alumno llega a un nivel.**

Se añade desde «Restricciones de acceso» en los ajustes de una actividad o de una sección, en los cursos donde el
juego está configurado. Como cualquier condición de Moodle, se puede negar y combinar con otras.

[Read in English](README.md)

## Requisitos

- Moodle 4.5 a 5.3.
- Oksigenia Tesapé (`local_oksigeniatesape`) 0.195.0 o posterior.

## Instalación

Copia este repositorio en `availability/condition/oksigeniatesape` (desde Moodle 5.0, `public/availability/condition/
oksigeniatesape`) y termina la instalación desde las notificaciones del sitio.

## Privacidad

No guarda datos personales: lee el progreso del juego.
